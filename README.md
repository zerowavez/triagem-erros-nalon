# TaskFlow Mobile

Aplicativo-base da UC14 — Executar testes, melhorias e versionamento de aplicativo mobile.

## Contexto

O TaskFlow foi desenvolvido por uma equipe terceirizada e entregue em versão beta. A nova equipe deverá avaliar o produto, registrar falhas, implementar correções e melhorias, organizar versões e preparar o aplicativo para publicação.

## Tecnologias

- React Native
- Expo
- TypeScript
- React Navigation
- AsyncStorage

## Como executar

```bash
npm install
npx expo start
```

Depois, execute no emulador Android ou no aplicativo Expo Go.

## Funcionalidades previstas

- Cadastrar tarefas
- Listar tarefas
- Editar tarefas
- Excluir tarefas
- Marcar tarefas como concluídas
- Filtrar tarefas por status
- Definir prioridade
- Persistir dados localmente

## Versão recebida

`0.9.0-beta`

## Missão da equipe

1. Executar e compreender o aplicativo.
2. Comparar o comportamento atual com os requisitos.
3. Registrar problemas com evidências.
4. Priorizar correções e melhorias.
5. Evoluir o aplicativo até uma versão pronta para publicação.
