# Requisitos do TaskFlow

## Requisitos funcionais

- RF01 — O usuário deve cadastrar uma tarefa com título obrigatório.
- RF02 — O usuário deve visualizar as tarefas cadastradas.
- RF03 — O usuário deve editar uma tarefa existente.
- RF04 — O usuário deve excluir uma tarefa após confirmação.
- RF05 — O usuário deve marcar uma tarefa como concluída ou pendente.
- RF06 — O usuário deve filtrar tarefas por status.
- RF07 — O usuário deve definir a prioridade da tarefa.

## Requisitos não funcionais

- RNF01 — Os dados devem permanecer salvos após fechar o aplicativo.
- RNF02 — O aplicativo deve apresentar mensagens claras ao usuário.
- RNF03 — A interface deve funcionar em diferentes tamanhos de tela.
- RNF04 — O aplicativo deve manter desempenho adequado durante a listagem.
- RNF05 — A versão exibida ao usuário deve corresponder à versão configurada no projeto.
